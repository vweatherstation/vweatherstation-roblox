# VWeatherStation Roblox Connect

Bring real-world weather into your Roblox game, or broadcast your game's weather to a live public dashboard. Free, no API key.

## Two modules (drop-in, no compiling)
- **`VWeatherConnect.lua`** — pulls real-world weather INTO your game (sky, fog, lighting, time follow the real world).
- **`VWeatherStationReport.lua`** — broadcasts your game's weather TO a live dashboard on VWeatherStation.

## Quick start
1. Add the `.lua` as a ModuleScript in `ServerScriptService`.
2. Enable **Game Settings → Security → Allow HTTP Requests**.
3. `require()` it and call `Start{}` — see the header of each file.

Full docs & live demo: **https://vweatherstation.com/roblox/**
